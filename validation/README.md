# Validation

See the [current evidence policy](../docs/VALIDATION.md), [release checks](../release/CHECKS.md) and [per-profile index](STATUS.md).

The early 2026-09-06 baseline covered 41 bounded profiles, 164 epochs, 1,992 final values and 10,702 internal/lifetime observations. These figures describe that historical batch only; the release index contains later results. Historical `native_application_checks` fields must be interpreted using [the native-evidence correction](../docs/contracts/NATIVE-EVIDENCE.md).

Retained reports distinguish source, compiler, simulator, arithmetic, protocol and performance outcomes. Full frozen run directories are deliberately outside the curated source package; a report link does not imply all of its referenced large artifacts are bundled.
