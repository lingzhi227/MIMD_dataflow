# Architecture review

The curated English architecture description is [here](../ARCHITECTURE.md). The original evolving review narrative is represented by the preserved development archive; use individual algorithm contracts for exact experimental details.

Review priorities are composable queue/task/microthread/DSR ownership; asynchronous buffer lifetime; stable host ABI; faithful reuse of CSL libraries; explicit numerical policy; and matched performance measurements on real hardware. This project does not claim Cerebras endorsement or unrestricted graph compilation.
